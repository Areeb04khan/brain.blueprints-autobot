# Instagram Shayari Bot

Automated Instagram Shayari poster built with Python and GitHub Actions.

The bot generates poetic content with Gemini, renders branded images with Pillow, optionally creates Reels with Urdu TTS and background music, uploads the media to a public host, and publishes it through the Instagram Graph API.

## Features

- Scheduled Instagram photo posts.
- Scheduled Instagram Reels.
- Gemini-generated structured Shayari content.
- Roman text, Urdu text, English translation, captions, hashtags, emotion, and source metadata.
- Square 1080x1080 photo generation.
- Vertical 1080x1920 Reel image generation.
- Urdu voiceover using Edge TTS.
- Background music mixing for Reels.
- Public media hosting through TempFile.org by default.
- Optional Cloudinary support for durable hosted media.
- GitHub Actions automation with bounded retries and job timeout.
- Progress tracking to avoid duplicate same-day posts.

## How It Works

The main script is `poster.py`.

For a photo post:

1. Selects a poet from `POET_SCHEDULE`.
2. Selects a format from `FORMAT_WEIGHTS`.
3. Calls Gemini to generate structured Shayari JSON.
4. Renders a square image using Pillow.
5. Uploads the image to the configured media host.
6. Creates an Instagram media container.
7. Publishes the post.
8. Saves progress in `progress.json`.

For a Reel:

1. Reuses the same `today_content` generated by the photo run when available.
2. Renders a vertical image.
3. Generates Urdu TTS audio.
4. Combines image, voiceover, and background music into an MP4.
5. Uploads the video to the configured media host.
6. Creates an Instagram Reel container.
7. Polls Instagram until video processing finishes.
8. Publishes the Reel.

## Requirements

You need:

- A GitHub repository.
- A Google Gemini API key.
- An Instagram Business or Creator account.
- A Meta Developer app with Instagram API access.
- GitHub Actions enabled.

The workflow installs Python dependencies and system packages automatically.

## Create Your Gemini API Key

1. Go to Google AI Studio.
2. Create an API key.
3. Save it as a GitHub Actions secret named `GEMINI_API_KEY`.

## Set Up Instagram / Meta

1. Convert your Instagram account to a Business or Creator account.
2. Go to https://developers.facebook.com/apps/.
3. Create or open a Meta app.
4. Add Instagram API / Instagram Business Login setup.
5. Connect your Instagram account.
6. Generate an Instagram access token.
7. Find your Instagram user id.

Add these GitHub Actions secrets:

- `INSTAGRAM_ACCESS_TOKEN`
- `INSTAGRAM_USER_ID`

To verify a token:

```bash
curl "https://graph.instagram.com/me?fields=id,username&access_token=YOUR_TOKEN"
```

The response should include your Instagram `id` and `username`.

## GitHub Actions Secrets

Open your repository on GitHub and go to:

`Settings` -> `Secrets and variables` -> `Actions`

Add:

- `GEMINI_API_KEY`
- `INSTAGRAM_ACCESS_TOKEN`
- `INSTAGRAM_USER_ID`

Optional:

- `CLOUDINARY_URL`, only if using Cloudinary.
- `CATBOX_USERHASH`, only if using Catbox.

## Media Hosting

Instagram Graph API requires a public HTTPS URL for the image or video before publishing.

This bot supports:

- `tempfile`: default, no secret required, temporary direct download URLs.
- `cloudinary`: recommended long-term, durable CDN URLs, requires `CLOUDINARY_URL`.
- `catbox`: supported but not recommended because anonymous uploads previously failed with `Invalid uploader`.

The workflow currently sets:

```yaml
MEDIA_HOST: tempfile
```

To use Cloudinary:

1. Create a Cloudinary account.
2. Copy the `CLOUDINARY_URL` value from Cloudinary settings.
3. Add it as a GitHub Actions secret named `CLOUDINARY_URL`.
4. Change the workflow env value to:

```yaml
MEDIA_HOST: cloudinary
```

## Running Automatically

The workflow is defined in `.github/workflows/main.yml`.

Current schedule:

```yaml
- cron: '30 2 * * *'   # Photo, about 8:00 AM IST
- cron: '30 13 * * *'  # Reel, about 7:00 PM IST
```

You can also run it manually from the GitHub Actions tab and choose:

- `photo`
- `reel`

## Customization

Change the Instagram handle displayed on images:

```python
IG_HANDLE = "@your_handle"
```

Change poets:

```python
POET_SCHEDULE = [
    {"name": "Mirza Ghalib", "era": "1797-1869"},
]
```

Change content format weights:

```python
FORMAT_WEIGHTS = [
    ("four-liner", 40),
    ("longer", 35),
    ("couplet", 20),
    ("one-liner", 5),
]
```

Change visual colors:

```python
EMOTION_PALETTES = {
    "ishq": {"bg": "#1a0010", "text": "#f5c6d0"},
}
```

Change the generation style:

- Edit the prompt inside `generate_content` in `poster.py`.

Change posting times:

- Edit cron values in `.github/workflows/main.yml`.

Change Reel music:

- Add or remove `.mp3` files in the `music/` folder.

## Common Problems

### Invalid OAuth access token

Example:

```text
Invalid OAuth access token - Cannot parse access token
```

Fix:

1. Go to https://developers.facebook.com/apps/.
2. Open your Meta app.
3. Go to `Instagram` -> `API setup with Instagram business login`.
4. Generate a new token for the connected Instagram account.
5. Copy only the token string.
6. Update `INSTAGRAM_ACCESS_TOKEN` in GitHub Actions secrets.
7. Re-run the workflow.

Tokens usually need renewal about every 60 days.

### Media could not be fetched

Instagram could not access the uploaded image or video URL.

Fix:

1. Open the logged media URL in a private browser window.
2. Confirm it downloads or displays without login.
3. Switch `MEDIA_HOST` to `cloudinary` if temporary hosting is unreliable.

### Catbox invalid uploader

Catbox rejected the upload.

Fix:

- Keep `MEDIA_HOST=tempfile`, or use `MEDIA_HOST=cloudinary`.

### Gemini returns bad JSON

Gemini occasionally returns malformed JSON.

Fix:

1. Re-run the workflow.
2. Tighten the prompt in `generate_content`.
3. Add stricter validation if it happens often.

### Reel generation fails

Possible causes:

- TTS service failure.
- MoviePy issue.
- FFmpeg issue.
- Large or problematic audio file.

The script tries to fall back to a silent FFmpeg-generated Reel when TTS fails.

## Local Test

Install dependencies:

```bash
pip install -r requirements.txt
```

Set environment variables:

```bash
set GEMINI_API_KEY=your_key
set INSTAGRAM_ACCESS_TOKEN=your_token
set INSTAGRAM_USER_ID=your_user_id
set POST_TYPE=photo
set MEDIA_HOST=tempfile
```

Run:

```bash
python poster.py
```

On Linux/macOS, use `export NAME=value` instead of `set NAME=value`.

## Notes

This bot posts content automatically to a real Instagram account. Test manually before enabling scheduled posting, keep your tokens private, and respect copyright and platform rules when choosing poetry and music.
